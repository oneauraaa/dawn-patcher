# dawn-patcher

Patches the [Dawn](https://dawn.gg) launcher: removes ads, reclaims the wasted
right-hand rail space, and declutters the top nav bar.

```powershell
irm https://github.com/oneauraaa/dawn-patcher/releases/latest/download/dawn-patcher.ps1 | iex
```

Run the same command again to revert to stock Dawn.
